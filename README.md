# 디데이 25

전남대 치전원 25학번 카톡 공지방(25 실습공지, 전남대치전원 25 공지방)에서
마감 일정과 실습 준비물을 정리해 보여주는 페이지입니다.

- `index.html` — 목록 페이지 (GitHub Pages로 바로 반영)
- `apps-script/app.js` — 실제 기능 코드. 여기를 고치면 5분 안에 반영 (다시 배포할 필요 없음)
- `apps-script/Code.gs` — Apps Script에 한 번만 붙여넣어 두는 로더. 실행 때마다 최신 `app.js`를 가져와 실행
- `apps-script/appsscript.json` — Apps Script 매니페스트(권한)

비밀값(관리자 키, 보기 키, AI API 키)은 이 저장소에 두지 않고
Apps Script의 **스크립트 속성**에 둡니다.

목록은 AI가 자동으로 정리한 것이라 빠지거나 틀릴 수 있습니다. 중요한 내용은 원문 공지를 확인하세요.
